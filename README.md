# Princess Travel — UI Design Walkthrough

Step-by-step UI design for **Princess Travel** (Amira Aboudeeb), built for Samuel Malke’s UI Design Assignment.

Walk the owner through each screen, capture feedback, and record sign-off — matching the UI Design Worksheet.

## What it includes

1. Intro — who the app is for  
2. Desk home — search, stages, booking list  
3. New caller form  
4. Booking detail (Sabre quote, travelers, checklist)  
5. Find-by-phone demo  
6. Owner feedback form  
7. Owner sign-off  

Sample content mirrors the real WhatsApp → Sabre → payment → pre-travel workflow. The desk works **alongside** Sabre Red (no Sabre API).

## Run locally

```bash
npm install
npm run dev -- --port 43141
```

Open [http://127.0.0.1:43141](http://127.0.0.1:43141).

## For the assignment

1. Open the link with Amira.  
2. Use **Next screen** and read the left “Say this to Amira” script.  
3. On step 6, type her feedback and click **Save feedback**.  
4. On step 7, approve the design for worksheet sign-off.  

Feedback and sign-off save in the browser (localStorage) on that device.
