# STRATA — Rock Identification Lab

Interactive companion for a geology rock-identification lab. Fill igneous, sedimentary, and metamorphic charts, use quick ID guides, and print only the charts for submission.

## Features

- Links to the three rock-identification YouTube topics from the handout
- Identification guides for common igneous, sedimentary, and metamorphic rocks
- Fillable charts matching the assignment columns and point values
- Worksheet comments prefilled (e.g. “Tastes salty”, “Fizzes in acid”)
- Soft hints for samples that already have printed comments
- Autosave in the browser + Print / Save PDF submission view with your name

## Run locally

```bash
npm install
npm run dev -- --port 43127
```

Open [http://127.0.0.1:43127](http://127.0.0.1:43127).

## Submit

1. Enter your name at the top.
2. Complete the three charts while watching the videos / examining specimens.
3. Open **Charts ready to submit** and use **Print / Save PDF**.

This app helps you organize observations; final rock names should match what you see in your lab samples and course videos.
